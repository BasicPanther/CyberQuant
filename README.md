# CyberQuant prototype

A self-contained browser prototype for **CyberQuant — Continuous Cyber Risk Quantification & Security Investment Optimization**.

## Live demo

The deployed prototype is available at [cyberquant.netlify.app](https://cyberquant.netlify.app).

## Run

Open [index.html](./index.html) in a modern desktop browser. No package installation, API key, or external service is required.

## Demo path

1. Select **Existing Company** to open FinServe Technologies.
2. Open **Payment Gateway** in Assets, then choose **Simulate New Threat Event**.
3. Review the updated risk context in **AI Risk Analyst**.
4. Use **Investment Optimizer** at ₹100L and choose **Optimize Budget**.
5. Change the amount in **Scenario Simulator** to ₹50L and run the scenario.

The New Company option provides the nine-stage onboarding workflow, CSV validation, demo-dataset options, review and baseline completion.
